# 项目复盘 · 问题记录

复盘旧版（v2.0.0 及之前）发现的问题，逐条记录，供第二轮分析时避坑。

## #01 用 Zotero 中转生成中间 CSV

**状态**：待修复

**现象**

原始 `.nbib` 数据先导入 Zotero，再导出成 CSV 才交给 Python。其实 Python 可以直接读 `.nbib`，Zotero 这一步没必要，还带来信息损失——比如 MeSH 主题词和作者关键词被合并在一起，PMID 也被替换掉了。

**影响**

- 流程不可复现，中间多了一个人工操作环节。
- 导出的表列多、噪音大。
- MeSH 受控词与作者关键词混为一谈，影响关键词分析的结论。

**建议**

直接用 Python 解析原始 `.nbib` 得到干净的中间数据，去掉 Zotero 环节。

## #02 作者姓名规范化不适用中文名

**状态**：待修复

**现象**

作者规范化只保留“姓 + 名首字母”（把很多不同的人统一成 `Zhang Y` 这种形式），中文名重名率极高，大量不同作者被当成了同一个人。

**影响**

- 高产作者统计严重失真（出现“发文两千多篇”的假作者）。
- 建立在作者基础上的合作网络不可信。

**建议**

换更可靠的作者消歧方式（结合单位、邮箱、ORCID 等），或明确声明作者维度的分析不适用。
