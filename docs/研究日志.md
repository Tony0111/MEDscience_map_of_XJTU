## 数据获取

检索近 5 年（当前为 2021–2025）的数据。基础检索式：

```
("Xi'an Jiaotong University"[Affiliation] OR "XJTU"[Affiliation])
```

由于 PubMed 单次导出上限 1 万条，改为**逐年检索并导出**（基础检索式 `AND 年份[dp]`）：

| 年份 | 命中 |
|---|---|
| 2021 | 4,563 |
| 2022 | 5,527 |
| 2023 | 5,081 |
| 2024 | 5,663 |
| 2025 | 6,816 |

- 范围取全校，不限定医学部：交叉学科、只要与西安交大相关的都纳入。
- 逐年导出会产生**跨年重复**（同一篇因电子版/纸质版日期差异落入相邻两年），后续**按 PMID 去重**即可。
- 原始数据（`.nbib`）放在 `data/raw/`。

## 数据清洗

用 Python 直接解析 `data/raw/*.nbib`（MEDLINE 格式），不再经过 Zotero。流程见 `notebooks/01_parse_nbib.ipynb`：

1. **解析单条记录**：按「标签 - 值」逐行读取，续行拼回；作者块从 `FAU` 开始，`AUID`（ORCID）与 `AD`（单位）归到当前作者。
2. **整理成宽表**：一篇文章一行，保留 `PMID / TI / AB / FAU / AD / AUID / MH / OT / PT / DP / JT / LID`，派生 `year / doi / first_author / n_authors` 等；多值字段用 `||` 分隔（已确认该串不会出现在作者、单位、MeSH、关键词里）。
3. **按 PMID 去重**：逐年检索会产生跨年重复，去重后保留最早出现的一条。
4. **作者身份归一**：每个作者条目分配 `author_key`（有 ORCID 用 ORCID，否则用「规范化全名 + 第一个单位」），
   同名不同单位不会被合并；`articles.csv` 里对应 `authors_key`。
5. **产出**：
   - `data/interim/articles.csv` —— 文章宽表（29,907 行）。
   - `data/interim/authors.csv` —— 作者长表（275,392 行），带 ORCID、单位和 `author_key`，供作者分析使用。
